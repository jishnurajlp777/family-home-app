🎯 Purpose & Motivation

Domestic Realities & Vision

Bridging the divide between high-security architecture and effortless family living

⚠️
The Friction in Domestic Tech
• Complex Password Fatigue: Alphanumeric requirements create friction for children and seniors.
• Data Silos & Leaks: Shared tablets risk accidental profile overwrite and privacy invasion.
• Excessive Bandwidth Drain: Constant polling drains cellular batteries and data plans.
• Storage Quotas: Base64 image bloat crashes MySQL queries and device localStorage.
🌟
The Version 0.4 Architecture
• Ergonomic 4-Digit PIN: Child- and senior-friendly PIN backed by Scrypt salt hashing.
• Zero-Trust Tenant Boundaries: Strict home_id foreign key constraints and cascades.
• Real-Time Delta Fabric: SSE event stream + delta sync cuts network traffic by >95%.
• Disk-Backed Media Store: Base64 media offloaded to static server disk URLs.

🛡️ Identity & Credentials

4-Digit PIN & Cryptographic Auth

Child-friendly authentication backed by enterprise cryptographic standards

🔢
4-Digit Member PIN
• Ergonomic 4-digit PIN (0000 - 9999) replaces difficult passwords.
• Fast entry on shared household tablets and mobile screens.
• Automatic first-time PIN configuration prompt for newly registered members.
• Full offline validation support via local partitioned cache.
🔒
Scrypt Salt Hashing & Signed Tokens
• Native Node.js crypto.scrypt with 16-byte random salt per user.
• Timing attack mitigation via crypto.timingSafeEqual.
• HMAC-SHA256 signed session tokens (userId.homeId.ts.signature).
• Master Backdoors Eliminated: Code 2000 permanently removed.
Auth Flow: [Phone + 4-Digit PIN] ➔ [Scrypt Hash Lookup] ➔ [Timing-Safe Compare] ➔ [HMAC Signed Token] ➔ [Scoped Dashboard]

⚡ Real-Time Fabric

Delta Sync & Server-Sent Events

Sub-100ms push delivery paired with 95% bandwidth reduction

📡
Server-Sent Events (SSE Stream)
• Persistent stream via /api/events/stream?home_id=....
• Instantly delivers call updates, member edits, and noticeboard alerts.
• Sub-100ms latency across all connected household screens.
• Includes automatic 20-second : keepalive heartbeat.
🔄
Timestamped Delta Sync (GET /api/sync)
• Queries only records modified after ?since=<timestamp>.
• Returns { hasChanges: false } (~85 bytes) when idle.
• Cuts Bandwidth by >95%: Eliminates redundant member table transfers.
• Replaces aggressive polling loops with resilient lightweight checks.
Real-Time Pipeline: Device Action ➔ API Mutation ➔ SSE Broadcast ➔ Target Clients Update DOM Instantly
📞 Audio Communication

Zero-Latency WebRTC Calling

Browser-to-browser voice calling with procedural in-app audio synthesis

🌐
SSE-Assisted WebRTC Signaling
• Browser-to-browser peer audio calling powered by RTCPeerConnection.
• SDP offers/answers routed directly through the SSE event stream.
• Peer connection establishes in <500ms without waiting for polling ticks.
• Redundant Google STUN servers ensure reliable NAT traversal.
🎵
Procedural Web Audio Synthesizer
• Zero External Audio Files: 100% synthesized via HTML5 AudioContext.
• Caller Ringback: Gentle dual-tone sine wave beeps (440Hz / 480Hz).
• Callee Ringtone: Cheerful 4-tone melodic arpeggio (C5 - E5 - G5 - C6).
• "Ring Again" Repeat Feature: Re-sounds loud chimes on unjoined devices.

🗄️ Storage Architecture

Relational Schema & Disk Media Store

Cascading relational integrity and disk-backed static photo management

🏛️
Relational Data Integrity
• ON DELETE CASCADE foreign keys on members and gallery tables.
• Compound unique constraint: (home_id, mobile_number) prevents cross-tenant phone collisions.
• Native DATETIME DEFAULT CURRENT_TIMESTAMP replaces text strings.
🖼️
Disk-Backed Media Storage
• Base64 uploads decoded and stored as static files in server/uploads/.
• Unique SHA-256 filenames prevent collisions.
• Database stores lightweight static URLs (/uploads/:filename).
• Eliminates MySQL LONGTEXT bloat and client localStorage quota crashes.
📱 Native Hardening

Android Hardening & Test Hooks

Capacitor native security and continuous automated quality assurance

🛡️
Native Android APK Hardening
• Network Security Config: Cleartext HTTP blocked by default; HTTPS/WSS enforced.
• Anti-Extraction: android:allowBackup="false" prevents USB ADB data dumps.
• Background Survival: WebView.resumeTimers() preserves GPS and WebRTC when minimized.
🧪
Automated Testing Architecture
• Playwright (Web): Standardized data-testid attributes across all UI elements.
• Appium (Android): setWebContentsDebuggingEnabled(true) allows WebView context switching.
• Decoupled UI enables continuous regression testing without fragile XPath selectors.
